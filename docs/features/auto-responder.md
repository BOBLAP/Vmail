# Répondeur automatique

Dans **Réglages → Répondeur automatique**, cocher l’activation et choisir un début
et une fin avec leur heure. Les dates utilisent le fuseau personnel affiché dans
le formulaire ; les secondes sont prises en compte.

Choisir **Texte brut** ou **HTML**, saisir le message et, si souhaité, l’objet de
la réponse. Le mode HTML propose gras, italique, soulignement et liste. Enregistrer
programme la période. Le bouton d’arrêt permet de la désactiver immédiatement.

Pendant la période, les panneaux principaux prennent une teinte rouge pâle. Une
tuile avec l’icône du répondeur indique « Mode répondeur actif jusqu’au … ». La
barre supérieure présente aussi cette icône, ouvrant les réglages. L’indication
change aux bornes horaires sans rechargement ; une modification dans un autre
onglet est reprise sous une minute ou au retour dans l’onglet.

Une seule réponse est envoyée à chaque expéditeur pendant une même période,
pour l’ensemble des comptes actifs. Les réponses figurent dans **Envoyés**.
Modifier le texte pendant la période ne relance pas les expéditeurs déjà traités.
Les imports historiques, spam, corbeille, listes de diffusion et messages
identifiés comme automatiques sont ignorés. Les réponses sont envoyées par
l’application à la réception des nouveaux mails : elle et son service de
traitement doivent rester en fonctionnement.
